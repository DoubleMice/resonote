# “SaaS 行业已死”——软件不再是资产

<div class="grid grid-cols-2 gap-4 mt-4 text-sm">

<div class="p-4 rounded border-l-4 border-red-400 bg-red-50 bg-opacity-30">

### 过去：软件像一座矿
- 开发是一次性投资、固定资产
- “做完了以后有点像一个矿，或者像一个工厂”
- 矿不能被随便搬走 → 软件公司安心收 license 费

</div>

<div class="p-4 rounded border-l-4 border-red-400 bg-red-50 bg-opacity-30">

### 今天：知识产权分分钟被复刻
- Web Coding + AI 把任何闭源软件“复刻走”
- 资产属性消失 → 软件公司失去定价权
- 越轻的软件死得越快

</div>

</div>

<div class="mt-4 p-4 text-base italic border-l-4 border-red-500 bg-red-50 bg-opacity-20">
“对于SaaS软件行业，如果还是坚持走闭源的路线的公司的话，我觉得基本上只有死路一条，不管是大公司还是小公司。”
</div>

# 明略相对幸运：核心价值是数据供应链

<div class="text-sm mt-2">软件可以被复刻，但数据不能——吴明辉把明略比作金融业的 Wind / Bloomberg：真正值钱的是数据。</div>

<div class="grid grid-cols-3 gap-3 mt-4 text-sm">

<div class="p-3 rounded bg-blue-50 border-l-4 border-blue-500">

### 标准数据源
爬虫抓公开媒体、秒针广告监测的曝光/点击/转化、客户 CRM、线下零售的供应链与库存数据

</div>

<div class="p-3 rounded bg-green-50 border-l-4 border-green-500">

### 数据供应链
采集 → 数据仓库 → 标签索引 → dashboard。SaaS 只是最表层的那一块

</div>

<div class="p-3 rounded bg-yellow-50 border-l-4 border-yellow-500">

### 战场式需求
“商场如战场”，客户每天都有 ad-hoc 分析需求，分析师要 stand by 随时拉数据、拼数据

</div>

</div>

<div class="mt-4 text-sm p-3 rounded border-l-4 border-purple-500 bg-purple-50 bg-opacity-30">
**推论**：一个分析师一个月的工作里可能有 80% 是某一类事的反复——这些今天都能交给 AI；前端服务客户最好还是人（客户需要情绪价值），但活大部分让 AI 干。
</div>

# 三层记忆 ≈ 嵌套学习

- 模型出厂那一刻参数就冻结，中心化服务无法为每个人调参
- 谷歌论文：把模型分高/中/低层，用不同学习速率持续调参
- OpenClaw 在 Agent 端解决了它：日记层、memory 层、soul 层，调整速率各不相同
- 白盒：用文本编辑器就能打开 soul 和 memory

<div class="mt-3 p-3 text-sm italic border-l-4 border-blue-500 bg-blue-50 bg-opacity-20">
“它形成了一个新的记忆的模式，使得它可以持续地去理解一个人的最新的状态。”

# 把龙虾变成团队协作者

# 定制软件开发：从人月到 token 管理费

<div class="grid grid-cols-2 gap-4 mt-4 text-sm">

<div class="p-4 rounded border-l-4 border-yellow-400 bg-yellow-50 bg-opacity-30">

### 新的收费模式
- 以前按人月、人日计价
- 将来：消耗 100 万美金的 token，再收 20 万美金管理服务费
- 卖软件 → 卖“我带 AI 替你干”

# 冲击：美国比中国大得多

<div class="grid grid-cols-2 gap-4 mt-4 text-sm">

<div class="p-4 rounded border-l-4 border-red-400 bg-red-50 bg-opacity-30">

### 美国：价值导向定价
- 软件按“替了多少个人”定价，license 费很高
- AI 一来，这套定价体系崩了——“美国就没戏了”

</div>

<div class="p-4 rounded border-l-4 border-green-400 bg-green-50 bg-opacity-30">

### 中国：成本导向定价
- 本来就是卷：服务商极大丰富，只能在劳动力成本上加溢价
- 换成 token 费 + 溢价，中国没压力

</div>

</div>

<div class="mt-4 p-4 text-base italic border-l-4 border-red-500 bg-red-50 bg-opacity-20">
“冲击得大得多得多，而且不仅仅是SaaS软件冲击行业，就是所有的这种知识密集型的这种服务行业都会遇到新的定价体系。”
</div>

<div class="mt-3 text-sm p-3 rounded bg-purple-50 border-l-4 border-purple-500">
**破局点**：只用普通 AI 的公司很快会被拉平（大家成本结构一样 → 客户压价）。要有 special 的 AI + 独有的数据 context，才能做出同行做不出的成果。
</div>

# 品鉴者：我品鉴故我在

<div class="grid grid-cols-2 gap-4 mt-4 text-sm">

<div class="p-4 rounded border-l-4 border-green-400 bg-green-50 bg-opacity-30">

# AI 的责任与权利：不给太多

<div class="grid grid-cols-2 gap-4 mt-4 text-sm">

<div class="p-4 rounded border-l-4 border-red-400 bg-red-50 bg-opacity-30">

- 客户打胜仗时需要 partner 陪着加班——人给情绪价值
