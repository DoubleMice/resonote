重估一切，文艺复兴---2026H1 AI行业观察

主讲：明浩 · AI 行业观察者

明浩在 7 月整理上半年材料时，回看了自己从 5 月到 7 月积累的图表和报告：每月约有 90 至 100 多张可视化图表、20 至 30 份 PDF，准备本期时又集中处理了约 200 张图表和四五十份报告。节目因此主要聚焦第二季度，也把问题从单个模型发布拉回到资本、硬件、产品与社会如何彼此牵动。

资本
CapEx 已经影响芯片、存储、网络和能源的价格与估值。
模型
前沿模型、开源模型与后训练应用同时加速。
产品
Agent 让软件从回答问题转向处理连续任务。

用文艺复兴理解一次行业重估

节目的标题借用了文艺复兴。明浩从那段历史里抽出三组同时发生的条件：印刷术降低知识复制成本，赞助人把资本交给创作者，新的人文主义促使社会重新讨论人的价值。放到 AI 上，他看到推理成本下降、巨头资本集中投入，以及智能体开始触及工作分工后出现的同一个追问：哪些责任仍应由人承担。

这套比喻也给节目安排了顺序。资本没有被放在通常的结尾，而是被提到最前面。原因很直接：2026 年第二季度的行业新闻，已经很难只用模型能力解释。数据中心的建设、芯片与内存的供给、能源和土地的配置、云厂商的现金流，都开始决定哪些技术路线能继续向前。

文艺复兴在节目中是一种观察视角：复制成本下降会扩大传播，资本会选择它愿意支持的方向，社会则需要重新安排人的位置。它不是对 AI 结果的历史预言。

资本开支把旧硬件公司带回叙事中心

明浩从个人电脑时代的厂商名单说起：英特尔、AMD、三星、美光、SanDisk、西部数据、希捷、英伟达、技嘉、惠普、戴尔和联想。这些名字在 2026 年上半年的财经新闻中频繁出现。他统计约 17 家相关公司后称，它们在上半年的平均股价增长为 192%，SanDisk 的涨幅超过 700%。这些是节目制作时点之前的市场数据，随后一两周的波动也已经很大，SanDisk 和美光都出现回调。

股价只是表面。明浩引用高盛的统计来说明资本开支预期为何不断落后于现实：市场在 2023 年底估计 2024 年 CapEx 增长 19%，实际增长 54%；对 2025 年的预期约为 20%，实际增长 73%。在节目当时的判断中，2026 年的增速可能达到 80% 至 100%，而 2027 年主要科技公司的合计投入有机会跨过万亿美元。这里谈的是资本开支的年度增速，不能把它与营收或利润混为一谈。

投资侧

科技巨头建设数据中心，采购算力芯片、内存、存储、网络设备，并支付能源与场地成本。

回报侧

AI 服务收入先承担折旧，随后还要覆盖固定成本和运营成本，才会进入毛利与利润。

Agent 工作负载让这张硬件清单变长。预训练阶段常以 GPU 和数据为核心，连续任务则还需要保存上下文、分配执行、访问工具和存储结果。明浩因此把内存、CPU、存储、TPU 与其他定制芯片都放进了推理基础设施。资本从云厂商出发，流向芯片代工、芯片、存储、网络、云设施和能源公司，市场也由此出现购买算力的一方与出售基础设施的一方。

存储的成本占比上升，周期规律并没有消失

节目给出了一组数据中心成本构成：AI 热潮前，存储约占建设成本的 2%；到 2026 年，主持人估计这一比例可达 18%。同一张成本表中，GPU 或算力芯片占 42%，冷却占 10%，能源占 15%，建筑占 15%。存储的绝对需求增加，价格也在上升；每代英伟达芯片对存储空间的要求继续增长，两种变化一起抬高了它的重要性。

这也解释了存储公司为何成为市场焦点，但明浩没有把它讲成一条单向上升曲线。他提醒听众，存储长期是周期行业：需求上升时建厂，产能建成后需求又可能回落，过去常见约四年的循环。美光的例子把这种波动压缩得很直观：节目称其 2023 年第一季度的毛利率曾为负 33%，到 2026 年 5 月可以达到 85%。这两个数字都来自节目转述，反映的是同一家公司在不同周期位置的毛利率，而非行业平均水平。

旧互联网泡沫时期的代表公司英特尔和思科，也被明浩作为另一种回归的标志。节目称，两家公司在过去 26 年里都没有超过 2000 年前后的股价高点，直到 2026 年或 2025 年末才重回这一位置。AI 的需求让硬件叙事重新有了中心位置，但它并没有取消供给过剩和价格回落的可能。

现金流、债务与云服务商的压力测试

大规模投资最难回答的问题，是收入何时能把设备成本转化为回报。明浩的判断是，截至 2026 年第二季度，整个 AI 行业的收入规模刚够覆盖巨额 CapEx 的折旧。若把收入继续用来承担固定成本、运营成本和利息，能够留下多少利润，还要看企业付费需求是否按预期增长。

节目把自由现金流和债务放在一起看。明浩称，主要科技公司的自由现金流自 2025 年第三季度开始下降，并预测 2026 年第三季度可能转负。Google、英伟达和 Meta 都在发债；大型科技公司信用更强，发债也更容易。另一端的风险在于高杠杆的云服务商。节目提到 CoreWeave 和 Nebius，认为市场担心的是利息负担与现金流，而不是单纯的算力供给规模。

节目没有替听众裁定这一轮投入是长期建设还是泡沫前夜。乐观者看到能力、渗透率和收入增长，审慎者看到企业落地速度、循环融资与债务风险；两组事实同时存在。

模型迭代加快，竞争不再只有一个领先者

进入模型部分后，明浩把 OpenAI 和 Anthropic 放在同一个问题下观察：模型能否越来越多地参与研究与训练自身的工作。OpenAI 的能力分级里，智能体之后是研究者；Anthropic 也讨论过让 AI 进入训练过程。节目据此归纳，厂商有不同产品叙事，但都在追求让模型承担更多连续工作。模型若能在有限环节提供反馈，发布节奏就可能继续缩短。

这种竞争同时变得更拥挤。明浩列举 OpenAI、Google、Meta、Anthropic 和 xAI，也提到 Mistral 与从头部实验室离职者建立的新实验室。代码、推理、多模态和长上下文并不总由同一家公司领先。节目制作时还观察到 Anthropic 在企业订阅与融资估值上的位置变化，不过这些比较随市场时点变化很快，重点在于模型竞争已从单一排行榜转为多场景、多产品线的并行竞争。

开源、闭源与后训练让中美路线彼此渗透

明浩用南北文艺复兴作了第二层类比。意大利式的委托创作昂贵而独特，北方的版画与印刷更便宜、可复制。节目将硅谷一侧概括为大规模算力驱动的闭源前沿模型和订阅服务，将中国一侧概括为更强调开源、高效、低价与扩散的路径。这是趋势判断，不是给每家厂商贴上的固定标签：节目也提到字节和千问的部分 Max 模型采用闭源策略。

技术传播使这条边界不稳定。明浩提到法律 AI 公司 Harvey 的实验：合作方后训练智谱开源的 GLM 5.1，在 Harvey 的法律榜单中排名第一。节目还提到 Cursor 的模型被发现基于 Kimi K2.5 后训练。基础模型的能力、权重开放程度、后训练方法和行业数据会在不同公司之间组合，资本投入的差异并不会阻断全部技术流动。

闭源
集中算力与产品收入，追求前沿能力和服务交付。
开源
允许后训练、部署和扩散，竞争会延伸到模型之后。
共同约束
芯片、资本、数据和企业需求仍决定可持续的速度。

世界模型包含三种不同的能力目标

透视法没有发明颜料，却改变了画家、建筑师和地图制作者表达空间的方式。明浩用它解释世界模型：AI 的预测对象正在从下一个词，扩展到世界的下一个状态。文本、图像和视频在训练时被放在一起，几何、物理和语义也被纳入同一套表征。

节目沿用李飞飞对世界模型的三种划分。渲染器面向人类视觉，重点是生成可观看的世界；模拟器面向物理规则，重点是还原状态变化；规划器面向机器人和自动驾驶，重点是为物理世界中的行动提供依据。三个方向都可能使用多模态数据，但对准确性、实时性和可行动性的要求不同。

因而，世界模型并不对应一条已经收敛的技术路线。明浩把杨立昆放在潜在空间预测状态的方向，把哈萨比斯与 DeepMind 放在多模态理解的方向，把李飞飞与 World Labs 放在三维空间表征的方向。视频模型、3D 生成、自动驾驶和具身智能公司都在使用这一术语，产品场景会决定各自需要解决的问题。

Agent 把产品交互改成任务执行

明浩认为，用户使用模型的方式已经从写提示词、等待回答，转成把一件任务交给系统。一个智能体需要规划步骤、调用工具、执行操作、发现错误并评判结果；多智能体系统则把不同步骤交给不同角色。人不必逐步输入每一条指令，但仍要检查目标、权限和结果。

编程是这条变化最清晰的战场。节目援引 Anthropic 的说法：Claude Code 发布后，内部技术员工的人均代码提交量增长八倍。明浩把 Claude Code 的出现视为一个可能被后人回看的节点，并把代码看作可供 Agent 调用的执行层。代码工具的竞争也因而牵动 Anthropic、Codex 和 Cursor 等产品。

面向 Agent 的软件接口随之变多。人类用户通常依赖 UI；Agent 需要的是可调用、可组合的命令和协议。CLI、MCP、A2A 以及各种运行时工具，被节目视为从 LLM 工具链向 Agent 执行工具链演化的证据。UI 不会因此失去价值，但软件需要同时服务人和自动执行程序。

中国的办公 Agent 产品开始密集出现

明浩列出了一个快速变动的产品地图：字节有 Trae 和 Coze，阿里有 Qoder、Moolerun 与悟空，腾讯有 Workbuddy、QQClaw 与 Marvelous，智谱有 ZCode、AutoGLM，Kimi 有 Kimi Code、Kimi Work。豆包和千问也在推与 Agent 有关的付费功能。产品名称很多，功能、界面和目标人群却有重叠，整合和淘汰因此难以避免。

节目还提到，豆包和千问下线了早期的智能体业务；明浩认为那类产品更接近提示词的打包。阿里则已对 Moolerun、悟空和 Qoder 进行整合。主持人把区分放在系统能力上：它是否真的能把任务规划、工具调用、执行和反馈连接起来。

产品的商业选择仍很开放。通用 Agent 该做哪些场景、应该向谁收费、按什么方式定价、To B 和 To C 如何分配资源，都还没有稳定答案。明浩的观察是，Codex 已经让行业见到一种较为统一的产品外观：一个人交代目标，系统显示待办、行动与结果。外观趋同不等于商业模式已经成立。

治理与商业衡量回到人的责任

当 AI 从代码走向金融、法律、医疗和企业服务，治理不再只是模型实验室的内部问题。明浩列出三组张力：创新与安全，主权与互通，效率与就业。针对伪造画像等风险，规则要能识别具体滥用，也要判断对通用图像能力的限制会带来什么代价。模型和数据跨境流动，各国的法规与利益又不一致，跨国协调因此很难简化为一条规则。

衡量商业价值也还没有成熟的答案。节目回顾了几个技术周期：电力最终以千瓦时而不是亮度进入商业计量；互联网从页面访问量转向会话和点击；移动互联网的流量又让位于 DAU、MAU 等使用指标。明浩用这条历史说明，单纯计算消耗了多少 Token，未必能衡量 AI 是否创造了足够的结果。

他给出一个当时的成本参照：美国头部企业软件公司每月 Token 成本约为 7,000 至 7,500 美元，软件工程师月均工资约为 1.5 万美元。两者比较的是月度成本，不是 AI 与工程师的能力比较。问题是，当 Token 成本继续上升，企业会怎样衡量结果、定价和人机分工。ROI、按结果计费和资本开支是否出现拐点，构成节目留给下半年的观察清单。

节目最后回到人的位置：智能可以更便宜、更普及，责任、长期手艺、真实关系和对传统的继承仍需要具体的人来承担与维护。
