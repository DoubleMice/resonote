# 为什么这一期值得听

<div class="grid grid-cols-3 gap-3 mt-4 text-sm leading-relaxed">

<div class="p-3 rounded bg-blue-50 border-l-4 border-blue-500">

### 01 模型变强之后

GPT-4o 让一批原本跑不通的流程开始可做；应用公司也因此直接面对模型厂商。

</div>

<div class="p-3 rounded bg-green-50 border-l-4 border-green-500">

### 02 垂类还剩什么

数据私有性、清洗管线、实时响应与客户习惯，哪些能抵住通用模型？

</div>

<div class="p-3 rounded bg-purple-50 border-l-4 border-purple-500">

### 03 Cursor 的警报

工程优化能改善成本，但上游模型既掌握 API 账单，也掌握下一代训练数据。

</div>

<div class="p-3 rounded bg-orange-50 border-l-4 border-orange-500">

### 04 赚钱先看毛利

高 ARR 不等于商业模式成立；应用要把模型推理成本计入自己的账。

</div>

<div class="p-3 rounded bg-red-50 border-l-4 border-red-500">

### 05 大厂的入口优势

字节的多模态能力、飞书的接口和既有工作资料，构成了另一类应用基础。

</div>

<div class="p-3 rounded bg-yellow-50 border-l-4 border-yellow-500">

### 06 不只做一个 App

持牌、线下、流程复杂的传统公司，也可能是 AI 改造最有价值的落点。

</div>

</div>

# 先拆市场：面向谁，怎样交付

<div class="grid grid-cols-2 gap-4 mt-5">

<div class="p-4 rounded bg-blue-50 border-l-4 border-blue-500">

### 面向个人：To C 与 Prosumer

编码、通用工作、演示文稿和陪伴产品大多从个人入口开始；体验、价格与习惯决定留存。

</div>

<div class="p-4 rounded bg-green-50 border-l-4 border-green-500">

### 面向企业：To B

标准化 SaaS 可以复制给相似客户；项目制则需要按企业的流程、数据和合规要求交付。

</div>

</div>

<div class="mt-4 grid grid-cols-3 gap-3 text-sm">
<div class="p-3 rounded bg-orange-50 border-l-4 border-orange-500">法律、金融、医疗、汽车等领域，常牵涉高价值决策。</div>
<div class="p-3 rounded bg-purple-50 border-l-4 border-purple-500">中国企业端更常见本地部署，客户会为数据安全准备算力。</div>
<div class="p-3 rounded bg-yellow-50 border-l-4 border-yellow-500">美国市场里，法律等垂类更常以 SaaS 的方式售卖。</div>
</div>

# 高价值场景，模型厂商也会进入

<div class="grid grid-cols-3 gap-3 mt-5 text-sm leading-relaxed">

<div class="p-3 rounded bg-red-50 border-l-4 border-red-500">

### 金融

OpenAI 招募量化背景人才；Anthropic 也请资深分析师标注估值模型的关键假设。

</div>

<div class="p-3 rounded bg-orange-50 border-l-4 border-orange-500">

### 法律与医疗

结果关系到诉讼、财富或生命安全，客户愿意支付，模型厂商也会把资源投向这里。

</div>

<div class="p-3 rounded bg-purple-50 border-l-4 border-purple-500">

### 企业服务

FDE 与驻场服务需要很多人。模型公司并非不能做，只是还未把它变成人力密集型业务。

</div>

</div>

<div class="mt-5 text-sm opacity-80">访谈里的悬念由此展开：模型公司的绝对能力很强，垂类应用凭什么继续存在？</div>

# 垂类数据的门槛，在于是否独有

<div class="grid grid-cols-2 gap-4 mt-5">

<div class="p-4 rounded bg-green-50 border-l-4 border-green-500">

### 有价值的数据

私有案件资料、机构研报、会议纪要或付费社群里的观点，通用模型不一定能直接取得。

</div>

<div class="p-4 rounded bg-red-50 border-l-4 border-red-500">

### 容易失效的数据壁垒

公开且非排他的资料，模型厂商也可以购买、重新整理。先做的人不必然能长期独占。

</div>

</div>

<div class="mt-5 p-4 rounded bg-yellow-50 border-l-4 border-yellow-500 text-sm leading-relaxed">
在金融场景，嘉宾特别区分客观信息与主观观点：前者需要准确，后者要进入交叉验证与观点分布的判断。
</div>

# 快，取决于任务有没有时效性

<div class="grid grid-cols-2 gap-4 mt-5">

<div class="p-4 rounded bg-red-50 border-l-4 border-red-500">

### 即时任务

十分钟后就要开会、演示文稿还没准备好时，结果更快出现会直接改变产品价值。

</div>

<div class="p-4 rounded bg-blue-50 border-l-4 border-blue-500">

### 长时间运行的任务

如果智能体在夜间工作四五小时，缩短到两三小时未必影响用户当下的体验，但仍会影响成本。

</div>

</div>

<div class="mt-5 p-4 rounded bg-green-50 border-l-4 border-green-500 text-sm leading-relaxed">
效率不是单一指标：它同时关系到时效、token 消耗与应用的毛利。评估产品时，要先问任务的时间窗口。
</div>

---

# 留存不只来自技术，也来自迁移成本

<div class="grid grid-cols-3 gap-3 mt-5 text-sm leading-relaxed">

<div class="p-3 rounded bg-blue-50 border-l-4 border-blue-500">

### 熟悉的界面

开发者习惯 VS Code 式工作区，未必愿意改用更偏结果交付的原生编码智能体。

</div>

<div class="p-3 rounded bg-purple-50 border-l-4 border-purple-500">

### 已验证的交付

用户在旧产品上持续得到满意结果，会形成品牌认知和切换成本。

</div>

<div class="p-3 rounded bg-green-50 border-l-4 border-green-500">

### 记忆与主动提醒

长期记住用户提过的事情，并在相关信息出现时主动通知，是陪伴类产品可能建立的另一层粘性。

</div>

</div>

---

# To B 的价值，是稳定地嵌进流程

<div class="grid grid-cols-2 gap-4 mt-5">

<div class="p-4 rounded bg-red-50 border-l-4 border-red-500">

### 企业不能接受的风险

幻觉、绕过既有 SOP、忽视风控、合规或审计流程，都会使产品无法上线。

</div>

<div class="p-4 rounded bg-green-50 border-l-4 border-green-500">

### 企业愿意购买的能力

理解本地部署、权限边界和固定工作流；必要时由人驻场，把智能体接进原有系统。

</div>

</div>

<div class="mt-5 p-4 rounded bg-blue-50 border-l-4 border-blue-500 text-sm leading-relaxed">
这也是垂类服务还未被模型平台完全覆盖的原因之一：产品能力之外，还要把企业的现实约束做进交付。
</div>

# 编码为何成为最热入口

<div class="grid grid-cols-2 gap-4 mt-5">

<div class="p-4 rounded bg-green-50 border-l-4 border-green-500">

### 用户愿意为高价值任务付费

编码及其衍生任务能直接产出可验收的交付物，用户更可能接受更高价格。

</div>

<div class="p-4 rounded bg-blue-50 border-l-4 border-blue-500">

### 模型也需要高价值任务数据

嘉宾认为，编码任务同时是训练智能水平的重要数据来源，因此大厂都想掌握这个入口。

</div>

</div>

<div class="mt-5 p-4 rounded bg-yellow-50 border-l-4 border-yellow-500 text-sm leading-relaxed">
产品竞争不只在编辑器界面。谁能把任务、模型、成本和用户工作习惯一起接住，谁才有持续性。
</div>

# C 端效率工具，正在按成本分层

<div class="grid grid-cols-3 gap-3 mt-5 text-sm leading-relaxed">

<div class="p-3 rounded bg-blue-50 border-l-4 border-blue-500">

### Chat

一问一答，不依赖本地文件、技能或复杂记忆；成本低，适合日常知识问题。

</div>

<div class="p-3 rounded bg-green-50 border-l-4 border-green-500">

### Work

面向研究、规划与较完整的工作任务；市场上已有不同厂商按这个入口命名产品。

</div>

<div class="p-3 rounded bg-purple-50 border-l-4 border-purple-500">

### Code

带入文件、技能与更多上下文，成本更高，却有机会把用户的需求直接变成交付物。

</div>

</div>

<div class="mt-5 text-sm opacity-80">主持人质疑这种分层会不会让用户停在最便宜的一层；嘉宾则从推理成本解释了产品方的动机。</div>

# PPT 赛道仍在增长，形态却可能改变

<div class="grid grid-cols-2 gap-4 mt-5">

<div class="p-4 rounded bg-orange-50 border-l-4 border-orange-500">

### 今天为何还做 PPT

企业汇报仍依赖大屏展示。AIPPT、Gamma 等产品把模板、素材和制作流程包装成明确场景。

</div>

<div class="p-4 rounded bg-blue-50 border-l-4 border-blue-500">

### 嘉宾的替代设想

HTML 支持动态交互和更丰富的展示。嘉宾所在团队已用 HTML 做内部研究总结和现场演示。

</div>

</div>

<div class="mt-5 p-4 rounded bg-yellow-50 border-l-4 border-yellow-500 text-sm leading-relaxed">
PPT 仍是常用的汇报载体；嘉宾期待交互式页面随着 AI 生成能力提升，逐渐成为另一种选择。
</div>

# 陪伴应用：黏性与付费是两道题

<div class="grid grid-cols-3 gap-3 mt-5 text-sm leading-relaxed">

<div class="p-3 rounded bg-purple-50 border-l-4 border-purple-500">

### 产品体验

角色、文风、行动描述和抽卡机制，能把对话做得接近游戏；记忆也能增强陪伴感。

</div>

<div class="p-3 rounded bg-red-50 border-l-4 border-red-500">

### 内容边界

访谈指出，部分产品会吸引年轻甚至未成年受众，内容尺度因而成为国内外都存在的争议。

</div>

<div class="p-3 rounded bg-orange-50 border-l-4 border-orange-500">

### 商业化压力

年轻用户支付能力较弱；一些产品转向擦边内容，是因为这条路径更容易赚钱，而非技术必然。

</div>

</div>

# 生成式世界的难处，是第一分钟

<div class="grid grid-cols-2 gap-4 mt-5">

<div class="p-4 rounded bg-purple-50 border-l-4 border-purple-500">

### 创作者可以等

熟悉游戏画面与世界观构建的用户，有更高容忍度；他们可能愿意等待一张图生成二三十秒。

</div>

<div class="p-4 rounded bg-red-50 border-l-4 border-red-500">

### 新用户不会等

对普通用户而言，第一次反馈若来得太慢，最初的惊喜不会出现，新增和获客都会受影响。

</div>

</div>

<div class="mt-5 p-4 rounded bg-green-50 border-l-4 border-green-500 text-sm leading-relaxed">
嘉宾的建议是先收窄客群：在模型速度仍有限时，优先服务能接受等待、也更愿意付费的创作者。
</div>

# 视频 wrapper 的繁荣与脆弱

<div class="grid grid-cols-3 gap-3 mt-5 text-sm leading-relaxed">

<div class="p-3 rounded bg-green-50 border-l-4 border-green-500">

### 用户看到的是简化创作

视频应用把剧本、脚本和分镜接在基础模型前面，让非专业用户更容易完成创作。

</div>

<div class="p-3 rounded bg-orange-50 border-l-4 border-orange-500">

### 平台看到的是使用模式

应用创新会增加底层模型调用；模型厂商因而能观察高频需求，也可能把能力收回平台。

</div>

<div class="p-3 rounded bg-red-50 border-l-4 border-red-500">

### 成本决定可持续性

图像与视频推理成本高。没有清晰付费人群和效率优势，收入增长未必能留下毛利。

</div>

</div>

# 字节的优势，在于模型与分发一起跑

<div class="grid grid-cols-2 gap-4 mt-5">

<div class="p-4 rounded bg-blue-50 border-l-4 border-blue-500">

### 基础模型跨过门槛

嘉宾认为字节的 Seed 系列没有掉队，尤其语音、图像和视频等多模态任务表现突出。

</div>

<div class="p-4 rounded bg-green-50 border-l-4 border-green-500">

### 应用已有入口

豆包、即梦、猫箱，以及更早的剪映和飞书，让字节不必从零寻找用户和工作资料。

</div>

</div>

<div class="mt-5 p-4 rounded bg-purple-50 border-l-4 border-purple-500 text-sm leading-relaxed">
访谈里的解释是：模型能力达到可用临界点后，上层应用会更好做；多模态积累又能让产品在内容任务中跑得更快。
</div>

# 飞书的旧接口，成了智能体的新入口

<div class="grid grid-cols-3 gap-3 mt-5 text-sm leading-relaxed">

<div class="p-3 rounded bg-blue-50 border-l-4 border-blue-500">

### 读

把文档链接交给智能体，按固定流程检查遗漏、上下文、风险和埋点；它还能读取评论。

</div>

<div class="p-3 rounded bg-green-50 border-l-4 border-green-500">

### 写

把研究结果写回文档或表格；定时检查产品接口，也能留下团队可共享的记录。

</div>

<div class="p-3 rounded bg-purple-50 border-l-4 border-purple-500">

### 管边界

同一人的智能体可以分成可读写与只读版本，供同事查询时只暴露指定文件。

</div>

# ARR 很高，仍可能是一笔亏损的生意

<div class="grid grid-cols-2 gap-4 mt-5">

<div class="p-4 rounded bg-red-50 border-l-4 border-red-500">

### 容易被忽略的成本

应用需要购买模型 API；模型供应商的毛利，变成了应用的推理成本。只看 ARR 会漏掉这一层。

</div>

<div class="p-4 rounded bg-green-50 border-l-4 border-green-500">

### 能收取溢价的产品

面向明确垂类、拥有可靠工作流的 Prosumer 产品，可能从愿意付费的用户那里得到更高价格。

</div>

</div>

<div class="mt-5 p-4 rounded bg-yellow-50 border-l-4 border-yellow-500 text-sm leading-relaxed">
嘉宾用传统软件作对照：AI 应用很难达到旧软件的高毛利，因此模型成本、增长效率和裂变都要一起看。
</div>

# 毛利，是应用和模型之间的分账

::left::

<div class="space-y-3 text-sm leading-relaxed">

<div class="p-3 rounded bg-green-50 border-l-4 border-green-500">

<div class="p-3 rounded bg-blue-50 border-l-4 border-blue-500">
更少的 token、更好的检索和更明确的垂类定价，会让这笔账更接近可持续。

# 判断一家 AI 应用，可以先问五件事

<div class="grid grid-cols-5 gap-3 mt-5 text-center">

<div class="p-3 rounded bg-green-50 border-l-4 border-green-500"><div class="text-xl font-bold">效率</div><div class="text-sm opacity-70 mt-1">准、快、省</div></div>
<div class="p-3 rounded bg-purple-50 border-l-4 border-purple-500"><div class="text-xl font-bold">留存</div><div class="text-sm opacity-70 mt-1">习惯与流程</div></div>

# 最终付款的人，决定整条价值链是否成立
