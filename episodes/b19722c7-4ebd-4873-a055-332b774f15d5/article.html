156：与 Henry 的 AI 季报 26Q1

嘉宾：Henry Yin，MOE Capital 创始合伙人

这一季的 AI 讨论，被几条看似分散的线索串到了一起：一个开源个人 Agent 在聊天窗口里走红；Claude Code 与 Codex 把编码产品推到竞争前台；研究人员开始把模型放进修改训练代码的循环；而裁员、招聘和算力建设也开始围绕 Agent 重新调整。Henry Yin 的判断是，模型能力仍然重要，但它已经不足以单独解释竞争格局。

OpenClaw 把 Agent 放进了人们已经在用的地方

节目从 OpenClaw 开始。它是一个开源的个人 Agent 框架，可以接入飞书、WhatsApp、Telegram 等聊天软件，并在本地计算机上使用文件和系统权限。它没有提出一项单独的新技术：循环调用模型、工具调用、记忆和定时任务此前都已存在。不同之处在于，它把这些组件接到熟悉的聊天入口上，让一个原本需要打开终端或网页的工具，变成可以随手发消息的个人助理。

本地运行带来实际的任务能力。模型不再只看用户主动上传的文件，也能在授权范围内读取电脑里的材料，处理日历、消息和其他工具。节目里一位重度用户让 OpenClaw 每十五分钟扫描短信和 Slack 消息；发现约会或承诺时，就创建日历事项。他还用它生成群聊摘要、追踪商品价格、规划旅行，并根据酒店照片和偏好筛选住处。这些任务的共同点是输入零散、频率很高，且横跨工作和生活。

但这种便利不能和安全切开看。权限越多，Agent 就越可能端到端地完成任务，也越可能触及不该触及的数据或执行不该执行的动作。节目没有把它描述成装好即可用的消费品：要把工作流调到稳定，用户仍要投入时间；把本地权限交给软件，也要求用户先理解风险边界。

本期的产品判断是：OpenClaw 的意义在于交互方式。它将模型带进已有聊天关系和移动端输入，而不是要求每个用户先进入一个新的 AI 界面。

为什么它在中国格外显眼

Henry 把中国的高热度归因于几层条件叠加。第一层是习惯：长期使用微信等聊天产品的用户，对在对话里调度工具的方式并不陌生。第二层是模型选择：OpenClaw 可接入不同的模型，而 Agent 的复杂任务常常需要几十次甚至上百次调用，单次推理价格的差距会被任务循环放大。第三层是开源生态，它给用户和服务商留下了更多组合空间。

这不意味着美国没有讨论 OpenClaw。Henry 的感受是，硅谷的独立开发者和创业者更在意它代表的新分发方式；许多研究人员则未必把它当作技术上的新发现。两种视角都合理：前者看见了一个能抵达更广泛用户的入口，后者则看见了一组早已存在的技术部件。

聊天入口

照片、位置和临时消息可以直接进入任务流，减少在手机、电脑和终端之间搬运信息的步骤。

模型成本

一次对话的价差未必明显；一个需要反复规划、调用工具和重试的 Agent 会把价差放大。

安全边界

本地文件和系统权限扩大了可做的事，也要求权限、审核和责任边界更清楚。

从模型竞赛到产品生态竞赛

OpenClaw 只是入口的变化。节目更大的判断是，头部模型厂商的竞争正在从基准分数延伸到产品生态。Claude Code、Codex 等编码产品之所以重要，不是因为写代码本身是一个孤立场景，而是因为它们训练了模型处理长任务：读懂要求、拆分步骤、调用工具、写代码、运行测试、发现错误后继续修复。

这解释了为什么节目把编码能力称作通用 Agent 的底座。个人助理若要替用户完成一连串工作，不能停留在给出建议；它必须能操作环境。模型需要理解文件、调用 API、运行程序，必要时在沙盒里试错。长上下文能够放进更多信息，却不能自动保证检索、文件解析、工具调用和权限管理都正确。真实产品中的失败，常常发生在这些环节。

对模型公司来说，产品还有另一层价值：它提供优化方向。基准测试无法覆盖所有工作流，而自有产品和 API 能留下用户在真实任务中卡住的地方。公司可以从中筛选有难度的任务和使用轨迹，再用于评估、训练或产品改进。模型、开发者工具和上层应用因此越来越像一个整体，而不是上下游彼此独立的生意。

节目用 Cursor 与 Kimi K2.5 的讨论举例：一款头部 Agent 产品可以在开源基模之上做微调和产品化，争议则可能落在许可证、披露、合规与自研能力的边界上。无论对事件细节如何评价，这都说明基模、训练、产品体验和商业合作正在重新分工。

自进化为何在这个季度变得具体

Andrej Karpathy 的 Auto Research 实验是本期另一条主线。它建立在 nanoGPT 之上：先用极简代码构造一个可以训练小模型的环境，再让 Agent 反复阅读结果、修改训练部分的代码、运行训练并比较指标。人类先在 program.md 中设定实验规则与目标；系统在这个范围内尝试修改，并根据结果决定保留还是撤回。

节目介绍的实验以 bits per byte 为评估指标。单轮包含改代码、短时训练和评估，大约十五分钟完成一次，因此一晚可以跑很多轮。Auto Research 在小模型中找到了二十多项有效改进，把训练时间从两小时多缩短到一小时多。这样的结果并不表示 AI 已经能独立选择研究方向，却让原本抽象的自我改进讨论有了可运行的样本。

Henry 把它放进更长的脉络：Google 的 AlphaEvolve 曾用 Gemini 优化 Gemini 的 kernel；其他团队也在探索让模型参与调试和研究流程。多条尝试在同一时期出现，使问题从能否想象转成适用范围有多大。

当前的关键限制不是循环本身，而是目标与验证。系统可以在清楚的搜索空间里高效尝试；研究者仍要决定优化什么，以及怎样确认改动没有带来新的问题。

可量化的任务先落地，主观判断仍留给人

自动优化最适合的场景，有很清楚的共同点：目标可以量化，反馈足够快，结果可以审查。训练时间、渲染速度、数据库查询和基础设施调优都符合这几个条件。模型每改一次，就能跑测试，知道自己是否向目标靠近；上线前，人还可以检查安全性和改动原因。

节目给出一个相反案例。一家公司想给网站做深色模式，分别让 Devin 和 Claude Code 运行一小时多，结果都没有完成。问题不在于生成颜色代码，而在于如何自动判断按钮和文字在暗色界面里是否舒服、是否一致。只要评价仍主要依赖人眼与主观判断，自动循环就缺少可靠的反馈信号。

因此，自进化更像一块逐步扩大的工程领地，而不是一条突然替代研究人员的直线。短期内，研究者的角色会更多地落在定义问题、设置约束、选择评估与审查结果上。

持续学习和世界模型仍在寻找合适的形态

持续学习关心的是模型部署以后能否继续获得知识、能力或用户偏好。最常见的做法是记忆和技能文件：内容放在文本中，用户能够查看、修改和删除。它易于使用，却会受到上下文容量与压缩损失的限制。另一条路径是更新一小部分模型权重，例如针对某次输入做局部调整。节目提到的 Test-Time Training 就属于这类探索，但它要求每次推理都伴随更复杂的基础设施操作，目前也主要在小模型上验证。

自进化则更侧重让系统改进系统本身。两者会在个人助理等场景中相遇：一个 Agent 既要记住用户偏好，也可能要学习怎样更好地完成任务。但它们尚没有得到一种既简单又可大规模部署的共同实现。节目将这一点保留为下一季度的观察对象，而没有把它当成已经解决的问题。

世界模型是另一条并行的探索线。节目把它的潜在用途分成两类：交互式媒体根据玩家行为实时生成后续世界；具身系统则从视频推导行动策略，或构造机器人可以反复试验的模拟环境。不同团队在 3D 建模、表征、策略和环境模拟上分别推进，方向尚未合流。

推理不只是 GPU 问题

当 Agent 从一次问答变成持续运行的工作流，推理的成本和系统结构都会改变。节目援引 GTC 期间的数字称，Blackwell 的推理性能提升 3.5 倍、token 成本下降约十倍；又提到 Google 对 KV Cache 的量化探索，目标是显著压缩存储需求。无论这些数字在后续产品中如何兑现，讨论的方向很明确：要让个人助理大规模部署，推理侧的优化不可回避。

同时，Agent 不只请求模型。它会启动沙盒、运行模型生成的代码、读取和写入文件、执行测试。因此 GPU 与 CPU 是不同环节的资源：前者承担模型推理，后者承担任务环境和程序执行。节目据此提醒，观察 Agent 基础设施不能只盯着 GPU，也要看 CPU、内存和运行环境。

组织开始按 AI 使用能力重新分配工作

技术讨论在节目后段落到劳动市场。Henry 提到 Amazon 年初裁员 1.6 万人、Block 宣布裁员 40%，也描述 Meta 组织员工学习 AI、以 token 消耗作为效率指标的做法。这些案例来自嘉宾在硅谷的观察与转述，不能被外推为所有行业都由 AI 导致裁员；但它们显示，管理层已经开始把 AI 使用能力放进效率、招聘与资本支出的语言中。

小团队的变化更容易看见。节目里，成长快的创业公司仍愿意招聘，因为时间窗口很重要；不过招聘重心从补足人数转向寻找能和 Agent 配合的人。主持人补充，中国公司也在思考用更少的人、更多顶尖人才和 AI 工具来做事。人数下降不必然等于成本同比下降，因为更强的人才和算力本身也更贵。

一则律师案例说明了这种变化的尺度。面对隔夜修改合同的要求，小型团队借助 Claude 发现客户提出的多项要求互相矛盾，随后提出异议、修改文本并写出说明，在两三小时内完成工作。这里没有把法律责任交给模型；变化在于，文本密集、约束明确的工作能被更小的团队更快地处理。

节目最后把问题推到社会层面：若算力、资本和高技能人才获得的收益越来越集中，劳动市场、城市资产与税收机制可能都需要适应。给 token 征税只是节目提出的政策设想，并非已经实施的制度。

本篇根据节目转录整理，保留了嘉宾的判断、条件与不确定性。下一季度值得继续观察的信号包括 DeepSeek V4、Computer Use 的实际进展，以及持续学习能否出现更简单的可部署方案。
