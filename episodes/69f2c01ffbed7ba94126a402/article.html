语言、coding、多模态，到底谁坐 AI 的主桌？

演讲者：未注明 · 来源：屠龙之术 · 发布时间：2026 年 4 月

这期演讲从一个明显的体感开始：材料刚做完，行业已经需要重讲。演讲者习惯每隔几个月整理一次 AI 行业，到了 2026 年春天，这个节奏被压缩到不足两个月。模型更新、产品发布和开源项目的热点轮替得很快，OpenClaw 甚至在同一份 PPT 的制作期间就从新鲜话题变成了需要重新命名的旧话题。

他用语言、coding 和多模态三张桌子来安排这场复盘。它们不是三条互不相干的技术路线：语言模型提供交互与理解，coding 让任务能够在数字系统中落地，多模态则把图像、视频和现实世界的知识接到一起。演讲的判断是，过去半年里 coding 坐在最显眼的位置；但这个判断并不意味着另外两张桌子已经失去价值。

模型要能行动，外围系统就变成产品的一部分

演讲者把近年的模型能力分成聊天、推理和任务型 Agent 三个阶段。聊天模型擅长回答问题，推理模型通过后训练和强化学习处理更复杂的推演，而 Agent 面对的是另一类要求：它要决定什么时候停止思考并行动，调用哪些工具、以什么顺序调用，还要在失败后改写计划。一次漂亮的回答并不等于一项任务能够跑完。

这也是 Harness 成为关键词的原因。演讲者用发动机和汽车的关系解释它：基础模型像发动机，性能再好也不能单独把人送到目的地；上下文管理、记忆、工具权限、评估反馈和任务编排，才组成让模型稳定执行的那辆车。OpenClaw 与 Claude Code 在这里把模型、多 Agent、交互层和执行层接在一起，形成任务运行环境。

上下文与记忆

任务需要知道此前发生过什么、用户要什么，以及哪些信息仍然有效。

工具与权限

Agent 必须能调用工具，也必须知道哪些操作不可越界。

反馈与编排

多轮执行的价值在于检查结果、修订路径，并协调后续步骤。

演讲者引用的 GitHub 项目整理也服务于这一判断。项目名称里反复出现 Agent、Skill、Code 等词，热门新项目被粗略分为大量围绕 Agent 生态的工具。这里的变化不只是给人写软件，也包括给 Agent 写软件。对普通使用者而言，coding Agent 和通用 Agent 的边界则在变浅：只要用自然语言交代任务、系统能交付结果，底层到底经过哪条实现路径未必重要。

为什么 coding 被放在主桌

早期 coding 产品主要做代码补全，帮助程序员在已有项目中写完某一段。演讲者认为，今天的产品边界已经延伸到完整生成、代码评审、调试和需求管理。能力外溢后，coding 不再只服务职业开发者，也成为制作网页、App、信息整理工具乃至个人工作流的一种入口。

现场材料把 GitHub 上的代码提交、新网站和新 App 的增加，当成 AI 辅助开发正在扩大供给的迹象。这个迹象并不自动说明新增产品有质量、能留住用户，演讲中也没有把两者混为一谈。它说明的是制作和试错的门槛在下降，更多人能够把一个想法变成可以运行的数字产品。

演讲者用一组假设性算例解释软件市场的担忧：传统开发一项相关任务可能需要六个月和 50 万元；低代码路径被设为六周和 5 万元；Vibe Coding 则被设为六小时和 50 美元。这组数据只用于说明成本结构一旦被大幅压缩，旧软件商业模式会承受什么压力。

OpenAI 与 Anthropic：用户尺度和企业尺度没有合并

演讲并没有简单宣布谁已经胜出。ChatGPT 仍在用户规模、留存和使用时长上表现突出，因此它在消费者产品侧的领先很清楚。Anthropic 则在企业端被描述为增长更快：企业默认选择的变化、模型覆盖范围和 ARR 是演讲者更重视的信号。

ChatGPT

演讲者用周活、月留存、日活与使用时长来衡量它的消费者产品位置。

Anthropic

演讲者用企业采用与收入增速来描述它在商业化竞争中的位置。

按现场引用的 2026 年 Q1 数据，OpenAI 的 ARR 为 250 亿美元，Anthropic 为 300 亿美元。演讲者随即补上一个关键条件：两家收入是否扣除了云服务渠道费用，可能并不采用同一口径。因此，这两个数能说明竞争的紧张程度，却不能脱离口径直接作出企业价值的终局排名。

竞争也体现在组织和产品取舍上。OpenAI 把 Chat、Code 和浏览器逐步放进一个产品环境；Anthropic 则不仅提供模型，也把围绕模型的 Harness 做进自身产品。演讲者把这种共同走向称为一体化：模型公司希望控制从交互到执行的更多环节，而不只出售一个模型 API。

版本、开源与多模态同时加速

现场列出了春节前后多家中国模型公司的发布时间。演讲者的感受是，大版本更新过去常以半年为单位，如今已经被更短的间隔替代。每次新模型发布时，上一代模型可能已在内部训练或测试；这让公开发布的版本看起来更像竞争过程中的一个切片，而不是稳定终点。

DeepSeek 在这张图里的意义也不同于单纯冲榜。演讲者把它放在能力与价格的组合上：即使不承担突破能力天花板的角色，较低成本下的强表现仍能压低行业价格，并改变开发者可用的选择。关于开源，他引用下载量和模型占比材料，认为中国公司已成为重要供给方，因此开源不再只是软件许可问题，也被带进中美 AI 竞争的讨论。

多模态并没有因为 coding 热潮而退场。演讲者展示的图片输出中，模型能组织直播界面的评论、榜单与商品卡，也能为四款游戏的联动海报补上版权说明和公司名。他据此认为，图片模型处理的不只是像素，还包括界面结构、行业惯例与对象关系。这些是现场演示的个案，不能代表模型在所有情境下的正确率；它们说明了多模态为何仍值得关注。

Sora 应用关闭被放进同一套资源逻辑。演讲者没有把关闭等同于视频生成没有价值，而是追问模型公司怎样在训练、服务已有用户和研发下一代模型之间分配 Token 与算力。产品架构、组织架构和资源优先级，在他的论述里是同一个问题的不同侧面。

软件重估与数据中心投资，是同一场压力的两面

演讲者把软件与 SaaS 股的下跌，放在两种仍然并存的观点之间。一方担心 AI 降低客户自建软件的成本，侵蚀原有软件公司的利润率和商业模式；另一方认为，领先软件公司仍能保持增长，AI 还会扩展市场规模。现场没有用一条股价曲线解决这场分歧。

他的解释进一步延伸到大型科技公司。收入和利润增长不一定能抵消 Capex 对现金的压力。演讲引用的材料称，三家云公司和 Meta 一年合计计划投入约 3,000 亿美元资本开支。数据中心、GPU、网络和电力设施需要先花钱，回报却未必同步到来；这让市场开始更在意自由现金流，也会下调对高增长公司的估值倍数。

硬件侧也不是只有 GPU。演讲者认为，训练阶段长期以 GPU 为中心；到了 Agent 的多轮编排和任务处理阶段，CPU、存储和光互连的作用重新被市场看见。他把 H100 租赁价格仍然偏高视为供给紧张的信号，但也强调，扩张并不能只靠资本承诺：先进制造、封装、产线设计、工人、土地、电力和政府审批，都会拉长建设周期。

巨额私募融资没有消除泡沫问题

演讲者引用的一级市场图表把 2026 年 Q1 称为创纪录的季度，投资金额约 3,000 亿美元。更显著的是集中度：前五大基金和前五大项目都吸收了约四分之三的资金。OpenAI、Anthropic、SpaceX 等少数大公司因此可以继续以很高的估值融资。

在他的解释中，公开市场调整后给成熟科技公司的倍数变低，而后期私募市场仍愿意给头部 AI 公司高估值，这让上市不再是唯一的融资出口。公司可以继续发股、融资或收购。这样的结构强化了头部竞争，也让市场关于泡沫位置的判断更难统一：有人把它看作尚未结束的增长期，有人已经在担心回调。演讲者没有替听众选择答案，只呈现了支撑这些判断的相互冲突的材料。

技术收益落地时，也会改变人的处境

短剧是演讲中一个很具体的例子。同一时期，红果短剧负责人宣布拿出 5 亿元支持真人短剧拍摄；演讲者同时引用 4 月 15 日的投放数据，称字节巨量引擎在 AI 剧上的消耗为 9,968.92 万元，并预计很快达到单日 1 亿元。这组并列材料显示，平台可以在公开表态上扶持真人内容，也会响应已经出现的 AI 内容投放与榜单需求。它不能说明长期胜负，却足以解释创作者为何会感到变化迫近。

数据中心也把抽象的 Capex 变成地方问题。演讲者展示星际之门计划的卫星图，认为多处建设滞后，并提到美国多个州在讨论禁令或暂缓措施。电价、用水、环境和审批，已成为居民与项目开发者要共同面对的条件。

结尾处，他借恩格斯暂停提出一层担忧：新技术可以带来 GDP 增长，工资和福利却未必立刻改善。他拒绝用历史大叙事轻易覆盖人的一生。AI 越擅长完成标准明确、不能出错的任务，人越需要决定哪些任务愿意交出去，哪些包含判断、风险和关系的事仍要自己承担。演讲的落点是，技术收益、成本和个人处境必须同时被看见。
