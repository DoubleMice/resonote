# 风险从新闻变成了看得见的火光

::left::

冲突当天早上，Bowen 先从新闻得知袭击；傍晚，他在棕榈岛听见拦截声，并从新闻确认导弹残骸落在附近。

他平时住在世界贸易中心附近，离棕榈岛较远；只是那天正陪父母住在棕榈岛。此前三年多的地区冲突并未让他在迪拜本地感到类似的物理威胁。

<div class="mt-4 p-3 rounded bg-red-50 border-l-4 border-red-500 text-sm leading-relaxed">
现场出现火情时，居民无法立刻判断落下的是导弹、无人机，还是拦截后的碎片；Bowen 先回到官方渠道确认情况。
</div>

::right::

<div class="flex justify-center items-center h-full pl-4">

# 空域关闭后，离境不等于更安全

::left::

不少朋友选择陆路前往阿曼首都马斯喀特，再从第三国起飞。Bowen 也询问了包车司机，但没有立即动身。

他的判断是：在空旷道路上行驶六七小时，同样无法确定沿途的防护与风险；因此先留下观察，同时保留陆路离开的选项。

一周后航班陆续恢复，他先让父母离开。为抢到最先能飞的航班，他前后买了约二十张全价、可退的机票；父母最终在复航后的第二天早上飞往上海。

::right::

# 工作恢复得很快，地点却成了新的风险判断

# 航班恢复，不代表枢纽恢复常态

::left::

Bowen 将父母送走后又留了一周。其后他把原定凌晨三点的北京航班换到傍晚：按他的观察，导弹和无人机多在凌晨一点至五点发射；这改变了他对出发时间的取舍。

离开当天，他看到阿联酋航空专用的 T3 航站楼异常空。节目中，他说除了阿联酋航空外，迪拜大部分航班仍停飞；阿联酋航空是当时少数能维持各目的地每日一班的选择。

::right::

# 稳定感来自防护，也来自信息能否被核验

::left::

Bowen 认为，政府每天公布拦截导弹和无人机的情况，至少让居民知道防护系统仍在运行；战事第三天，阿联酋总统与迪拜王储在 Dubai Mall 露面的画面，也被他理解为安定人心的信号。

他同时看到另一面：阿联酋严厉处置网上传播的虚假信息，AI 生成的视频很快减少。这或许降低恐慌，却也会压缩公众自行了解现场的空间。

::right::

# 在不确定中，日常可得性是最直接的交叉检查

Bowen 回忆，政府呼吁居民不要囤货时，他打开 Deliveroo 发现水已售罄，新鲜水果也无法配送；平时可在约三十分钟送达的超市订单，当时显示无货。

<div class="rn-note rn-note-wide mt-4" data-note-diagram="cross-checks" role="group" aria-label="Bowen 用来判断局势的日常信号">
<div class="rn-note-cards grid grid-cols-3 gap-3">

# 金融中心的脆弱处，未必只在金融业

::left::

Bowen 说，金融业并非迪拜 GDP 中压倒性的部分；旅游、酒店和航运同样重要。对游客而言，炎热潮湿的六月至十月并不适合旅行，一年适合旅游的窗口本就有限。战事若延续，会先蚕食这个窗口。

他还估计，约一千万人口中有八九百万是外来人口。投资、资产配置和居住地都有可替代选项，因此长期拉锯比一时的市场波动更可能影响景气度。

::right::

<div class="rn-note" data-note-diagram="long-term-exposure" role="group" aria-label="Bowen 认为长期冲突影响迪拜的几个渠道">
<div class="rn-note-cards">
<div class="rn-note-card"><div><strong>安全感</strong><p>长期零星袭击会改变居住和投资判断。</p></div></div>
<div class="rn-note-card"><div><strong>旅游季</strong><p>可旅行月份有限，错过后难以补回。</p></div></div>

# 不确定时，先保留行动空间

Bowen 把这段经历归纳为：让判断有更多可用信息，核验日常信号、为出行准备可替代路线，再随着局势调整计划。

他也提醒，人在最初一两天没有既有经验可以套用；随着时间过去，会逐渐适应。适应并没有消除风险，只是让下一步决定不必完全靠猜测。
