AI 产品智能体投资观察

OpenClaw 热潮的来处与去向

嘉宾：庄明浩，科技投资人、图灵之书主播

来源：图灵之书 × 知本论 · 2026 年 4 月

这场对谈选在 OpenClaw 热度开始回落时回看它。庄明浩不把它当作突然出现的新智能，而把它放在模型能力、工程封装和用户情绪交汇的位置：基础模型在不少场景已经足够强，普通人却没有一辆能把发动机真正开上路的车。OpenClaw 把记忆、偏好、工具、本地文件与即时通信接到模型上，让人第一次比较直观地看到，AI 可以不只聊天，也能在电脑环境里完成一段工作。

产品

模型能力要接入工具、上下文与验收，才可能从回答问题走到完成任务。

成本

复杂任务会消耗更多 Token，把压力传到数据中心、电力与基础设施。

市场

开源生态带来低成本试错，也放大了估值、现金流与周期判断的难题。

模型之外，才是任务系统

庄明浩用发动机和汽车解释其中的差别。大语言模型和推理模型像发动机，OpenClaw 更像一套简易车架：它没有替模型增加一种神秘能力，而是让模型能记住偏好、使用工具、读取本地文件，并和既有通信软件连通。只让它查新闻、搜索资料或整理报告时，它未必胜过已经优化过的聊天产品。任务变成多阶段的编程、资料处理或工作流，并且每一步都要交付和验收时，这套架构才显示出作用。

但车架本身不能替人定义目的地。受访者把刚安装的 Agent 比作刚入职的人：它有基础能力，却不知道团队的规范、流程、上下游、数据库和产出格式。用户要逐渐提供这些信息，开放合适的工具和权限，再根据结果纠正配置。庄明浩因此说：它不是一个安装好了用就结束的事情。 同一套软件落在不同人手里，会因为任务、工具和反馈方式不同，呈现完全不同的效果。

节目所说的养，指让 Agent 熟悉任务边界、工作资源和结果标准的过程。复杂程度越高，使用者的判断越重要。

个人先能试，企业要先处理边界

从市场采用看，庄明浩认为当前 To C 的尝试更多，企业落地相对慢。企业已经较少争论该不该使用 AI，而是在追问用在哪个环节、是提升效率还是重做流程、该找模型厂商、软件公司还是内部团队。模型和 Agent 降低了按需求制作软件的成本，因此既有 SaaS 和软件订阅受到挑战；这并不意味着企业可以立刻替换原有系统。

企业内部有数据如何流转、谁能访问什么、隐私和安全如何保障、流程如何衔接、考核如何调整等问题。它们决定了部署不是一次产品安装。受访者承认市场上同时存在两种判断：一种认为企业会在很短时间内从观望变成争抢；另一种认为这些组织条件仍需要时间处理。

权限带来能力，也把风险暴露给更多人

OpenClaw 的传播把这件事推得尤其直接。庄明浩说，项目最初由个人开发者为了自己的需要制作，默认使用者有能力判断哪些权限安全、哪些行为危险。原始本地版本可以被赋予电脑的全部权限。它从极客工具走向大众使用后，版本更新频繁关注安全、隐私和权限，原因正是原来的假设已经不成立。

给 Agent 一台电脑或一个浏览器，会让它能做更多工作，也会扩大它接触文件、数据与实际操作的范围。此前不少厂商把 Agent 限制在具体场景内，既是成本考量，也是在避免把风险扩散出去。节目由此把安全从狭义的网络安全，延伸到个人、公司、行业和政府都要处理的现实问题。

Token 把产品体验连到基础设施

庄明浩把 Token 称作发动机的燃料，背后是数据中心和电力。早期的聊天式交互可能只持续几十秒；他观察到，先进模型已经能持续运行十几个小时的任务。编程、搜索、图像识别和视频生成等任务一起出现，消耗与一次简短问答并不在一个量级。用户并非有错，只是需求的形态变了，供给侧也随之承受压力。

这让所谓算力过剩的说法显得过于简单。受访者认为，模型厂商和云厂商仍然普遍面对算力紧张：一边是数据中心投入、单位 Token 成本下降，另一边是任务变长、调用变复杂，模型还要同时服务研发、企业客户和普通用户。不同业务之间需要排优先级，调用次数和服务范围也会受到限制。

为什么中国的热度更强

庄明浩把热度差异归于用户的使用起点。美国的主流 AI 用户已经沿着 ChatGPT、Claude、Gemini 等产品逐步接触了更复杂的能力，因而可能把 OpenClaw 看成适合一部分个人场景的小工具。中国的许多用户此前仍以对话产品为主，Agent 开始订餐、叫车或完成任务时，交互从聊天跳到行动，带来的感受更强烈。

他不为这种热度直接定义泡沫，却认为它有一层积极作用：更多人从让 AI 回答问题，转向让 AI 做事。中国的 To C 市场相对成熟，美国的 To B 市场相对成熟，产品把能力交给用户时需要适配不同的路径。热度本身不能证明商业价值，但它会推动模型、云、Token 与互联网平台一起面向更广泛的任务需求。

开源项目与早期投资如何改变试错

OpenClaw 项目本身不按传统公司的方式直接盈利，庄明浩认为很难替它的作者、贡献者和软件本身给出狭义估值。阶段性的影响力、传播、覆盖和生态，却可以被市场观察到。安装服务、培训课程、硬件和 Token 因此围绕项目出现。高门槛和用户焦虑之间需要中间服务，卖课往往最先赚钱；这描述的是热潮里的分工，不等于这些服务能长期代表项目价值。

AI 也在改变早期项目获得支持的方式。庄明浩不认同早期资本从此没有意义，但他认为启动成本降低、变化更快，小团队可以反复尝试多个方向。他举例说，Koji 与真格基金合作，为 AI 初创者或个人提供价值 5 万美元的 Token，先让对方做出东西，再判断是否值得继续投资。这种资源用于更早的产品验证，投资判断仍要看作品与项目。

小团队得到的空间

技术人员可用较低的初始成本，把原本需要较大团队的设想做成可测试的产品。

没有消失的约束

项目仍要找到需求、收入和可持续的工作内容；能调用 AI 不等于商业模式已经成立。

这也是他看待一人公司的角度。AI、供应链和互联网工具扩大了个体能力，但不能自动创造一个足以养活自己的职业。节目中的在线教育案例说明，几十人的团队可以拆成十多家小公司，让内容研发、线下运营等角色各自承接更多业务；原有的工作没有消失，只是组织方式变得更细。能否拆分仍要看任务是否能独立交付、是否存在外部需求。

市场的增长与紧张同时存在

庄明浩用一条产业链来说明二级市场的难题：用户购买应用，应用运行在模型上，模型依赖云，云落在数据中心和芯片上，芯片还要经过代工。每一环都可能从需求增长受益，也都可能面对成本。应用要承担模型与云的调用费用，模型既服务客户又训练新模型，云厂商与基础设施供应商则持续追加资本开支。

收入增长不能自动消除这些压力。受访者特别关注大型投入对现金流的影响：市场相信需求会持续扩张时，链条可以共同向上；如果情绪转向，原先相互加强的估值也可能一起回落。他把这种状态压缩成一句判断：市场永远都是有效的，市场永远都是过头的。 对当下的人来说，很难知道自己正站在技术和资本周期的哪一段，答案通常只能在多年以后回看时才清楚。

Agent 会继续向更少干预的方向走

受访者把脚手架、Harness 和环境搭建放进一个更长的方向：让 AI 自己检查任务节奏、发现偏差、寻找方案并纠正错误。他称之为自主进化。简单程序生成等场景已经接近可用，复杂场景还要跨过领域验证、监管、安全、隐私和权限这些边界。节目借用 OpenAI 的五级框架，把当下放在 L3 Agent，随后是能做研究员工作的一层，以及把强大个体组织起来的一层；并没有给出实现它们的时间表。

投资与使用的选择因此没有一条统一答案。庄明浩没有推荐具体标的，也没有断言热潮何时结束。他把判断放回参与者自己的风险承受能力、所处阶段和持续观察：产品能否完成真实任务，企业流程能否接住它，收入是否覆盖投入，市场又是否还愿意为下一轮增长付费。
