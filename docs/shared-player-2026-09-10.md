# 全站共享播放器：构建与验证记录

生产构建已改为一套 Slidev 播放器、每集一个内容 JS 包。当前 276 集、9,138 页只需执行一次 Vite 构建；浏览器打开一集时，不会下载其他集的正文。原有 `/episodes/<id>/#/页码` 地址继续使用，各集仍有轻量 HTML 入口，跨集链接仍采用普通页面导航，公共 JS 可复用浏览器缓存。

## 加载方式与缓存

`dist/player/` 保存公共播放器、主题和依赖。每集的页面组件、标题渲染与讲稿合并到独立的内容包，HTML 提前加载本集内容，播放器等本集路由就绪后启动。Mermaid 仅由使用它的集加载。单集配置、封面、页码、字体和资源基路径保持独立。

构建时检查三个条件：每集只有一个内容包；公共运行代码不能依赖内容包或内容索引入口；普通播放器的静态依赖不能包含 Mermaid。浏览器回归还验证了修改一集正文后，其他集内容及公共播放器的文件名保持不变。新增样式、功能或依赖仍可能改变公共文件。

构建缓存迁移到 `.cache/shared-player`，Actions 的缓存路径与键已同步更新。任何幻灯片或构建输入改变都会触发一次完整编译；文章和篇目导航在组装阶段更新。当前机器冷构建约 31 秒，已有缓存时约 5 秒。Node 堆默认上限为 2 GiB，实际完整构建峰值约 5.4 GiB；堆上限不等于整个构建进程的内存占用。

新集的编译错误只在能定位到源文件且该集属于本轮生成时隔离；多个新集错误可以一并隔离后重试。旧集回归、无法归属的编译错误和站点错误仍阻止发布。

## 浏览器测量

| 指标（10 轮中位数） | 调整前 | 共享播放器 |
| --- | ---: | ---: |
| 首张内容就绪 | 577.4 ms | 501.6 ms |
| 首次绘制（FCP） | 256.0 ms | 296.0 ms |
| 首屏 JS 请求 | 22 个 | 8 个 |
| 首屏同源子资源（gzip） | 220.4 KiB | 275.9 KiB |
| 立即翻到第 2 页 | 28.2 ms | 22.8 ms |
| 立即跳到第 20 页 | 83.6 ms | 26.6 ms |
| 预加载后翻页 | 19.9 ms | 20.4 ms |

首张内容就绪时间缩短约 13%，远距离跳页缩短约 68%。预加载后的翻页差异很小。首屏同源子资源增加约 25%，因为本集内容一次加载，公共播放器也包含跨集共享的功能；在低带宽环境下，这部分下载成本仍需考虑。38 页截图逐一比较，全部一致。

测速使用硅谷101 E249（38 页），在 Chromium 中按交替顺序测量两种构建，各 10 轮，每轮使用新的浏览器上下文。条件为本地 gzip 服务、40 ms 网络延迟、10 Mbps 带宽、4 倍 CPU 限速。第三方 HTTPS 依赖从同一份 HAR 回放，因此不包含这些服务的真实网络延迟。

“首张内容就绪”指对应页面 DOM 出现、字体就绪，再等待两帧，不包含翻页动画结束。FCP 可能只代表导航或背景出现，因此不能单独表示幻灯片已经可读。HAR 路由会关闭 HTTP 缓存；“预加载后翻页”复用的是已经加载的模块和 DOM。

另做了一次保留 HTTP 缓存的跨集检查：本地服务器设置 `max-age=3600`，用 CDP 阻止第三方 HTTPS 请求，连续打开两集。第二集复用了 7 个公共 JS 请求，传输字节数为 0。这验证缓存复用机制，不代表线上网络条件下的测速结果。

## 兼容性检查

- 101 项测试通过；新增真实编译和浏览器用例覆盖不同画布比例、标题转义、局部页码、讲稿、子路径部署、Mermaid 按需加载、缓存稳定性及错误归属。
- 全部 276 集的 HTML 指向同一个播放器入口，各自对应独立内容包；最早和最新样本的键盘翻页、刷新、旧链接、总览与演讲者视图通过检查。
- E249 的 38 页截图与旧构建逐一比较，全部一致。
- 5 集中 28 处 `./public/…` 图示引用在构建时转换为实际公开路径，28 张图均验证可渲染；源码文件没有改写。另验证了包含两个 Mermaid 图的页面与自定义字体的集。
- 首页交互、品牌检查及本次涉及脚本的 TypeScript 检查通过。

适配器针对固定的 Slidev 52.18.0，仍使用 Slidev 自身的渲染、布局和交互功能。升级版本、使用其他主题或加入单集自定义构建扩展，需要更新适配器并重新检查。此次修改未部署到线上。

## 复现

旧站快照保存在 `logs/shared-player/before/`。在新的工作区复现时，需要先提供同版本旧构建快照；本仓库不提交构建目录、HAR 和截图。

```bash
pnpm run build
pnpm test
pnpm run verify:routing
pnpm exec tsx scripts/experiment-slide-bundling.ts --shared-player --runs=10
```

完整测量与原始样本见 [shared-player-2026-09-10.json](shared-player-2026-09-10.json)。当前工作区的截图及实验输出位于 `logs/shared-player/experiment/6242033d-a14a-44e3-a622-cbfc7d3c3817/`，额外图示截图位于 `logs/shared-player/feature-*.png`。
